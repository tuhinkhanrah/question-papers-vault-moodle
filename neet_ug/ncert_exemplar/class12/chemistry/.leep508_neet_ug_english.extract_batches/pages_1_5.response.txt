  <generalfeedback format="html"><text><![CDATA[<p><strong>Step 1: Conceptual Principle</strong><br/>A disproportionation reaction is a redox reaction in which a single element in one intermediate oxidation state is simultaneously oxidised to a higher oxidation state and reduced to a lower oxidation state.</p><p><strong>Step 2: Evaluation</strong><br/>Examine the oxidation state changes in each reaction:<br/>In \(\mathrm{Cu}^{+} \rightarrow \mathrm{Cu}^{2+} + \mathrm{Cu}\), copper changes from \(+1\) to \(+2\) (oxidation) and \(0\) (reduction). This is a disproportionation reaction.<br/>In \(3\mathrm{MnO}_{4}^{2-} + 4\mathrm{H}^{+} \rightarrow 2\mathrm{MnO}_{4}^{-} + \mathrm{MnO}_{2} + 2\mathrm{H}_{2}\mathrm{O}\), manganese changes from \(+6\) to \(+7\) in \(\mathrm{MnO}_{4}^{-}\) (oxidation) and \(+4\) in \(\mathrm{MnO}_{2}\) (reduction). This is a disproportionation reaction.<br/>In \(2\mathrm{KMnO}_{4} \rightarrow \mathrm{K}_{2}\mathrm{MnO}_{4} + \mathrm{MnO}_{2} + \mathrm{O}_{2}\), manganese is only reduced (from \(+7\) to \(+6\) and \(+4\)), while oxygen is oxidised from \(-2\) to \(0\).
